Connecting a reader

Replace books.example.com below with this server's address. Sign-in is the username and password you were given; there is no self-registration.

KOReader — catalog

  1. Search → OPDS catalog → +
  2. Title: tsundoku
  3. URL: https://books.example.com/opds/1.2
  4. Fill in your username and password.

Long-press a book to download it.

KOReader — progress sync

  1. Tools → More tools → Progress sync
  2. Custom sync server: https://books.example.com — the base address, with no path after it.
  3. Choose Login, not Register. Registration is disabled and answers 403.
  4. Set Document matching method the same on every device. binary is the default and the right choice; filename breaks as soon as you rename a file.
  5. Turn on Send document metadata if you want titles to appear beside positions in the web UI.

Thorium Reader

Catalogs → Add catalog → https://books.example.com/opds/2.0. Thorium speaks OPDS 2.0, so give it the JSON feed.

Everything else

FBReader, Moon+ Reader, PocketBook, Panels and Aldiko all speak OPDS 1.2. Give them https://books.example.com/opds/1.2 with the same credentials.

Checking it by hand

curl -u you:secret https://books.example.com/opds/1.2
curl -u you:secret -H 'Accept: application/opds+json' https://books.example.com/opds/2.0/new
curl https://books.example.com/healthcheck
